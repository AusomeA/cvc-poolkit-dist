# PoolKit distribution files

Password-protected build files for PoolKit, an Unreal Engine 5 pooling plugin by Barbed Wire Glove Games LLC,
used for marketplace review. These files are not free downloads.

Get PoolKit on itch.io: https://barbed-wire-glove-games.itch.io/poolkit
Documentation: https://github.com/AusomeA/cvc-poolkit-docs
